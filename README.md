# ИС «Книжный магазин»

Курсовой проект по МДК.01.01 «Разработка программных модулей».
Автор: Агафонов Д. А., группа 324, специальность 09.02.07.

Настольное приложение для книжного магазина с одной торговой точкой: каталог книг с поиском,
фильтром по жанру и сортировкой по цене, автоматическая скидка 25 % на книги без заказов
в прошлом календарном месяце, оформление заказа с контролем остатка, просмотр и удаление
заказов сотрудниками, изменение даты и удаление позиции администратором.

## Версии

| Компонент | Версия |
|---|---|
| .NET (целевая платформа) | net10.0 |
| Avalonia | 12.1.3 |
| Entity Framework Core (SqlServer, Design, dotnet-ef) | 10.0.12 |
| СУБД | Microsoft SQL Server 2025 (17.x), сортировка Cyrillic_General_CI_AS |

## Роли

| Роль | Возможности |
|---|---|
| Гость (пользователь не выбран) | просмотр каталога, поиск, фильтр, сортировка |
| Покупатель | + карточка книги, заказ на себя |
| Продавец | + заказ на выбранного покупателя, список и состав заказов, удаление заказа |
| Администратор | + изменение даты заказа, удаление отдельной позиции |

Вход выполняется **выбором логина без пароля** — это учебная демонстрация ролей,
а не защищённая аутентификация.

## Состав папок

```
src/Ktpt.Bookstore/     приложение Avalonia (Models, Data, Services, Views, Assets)
database/               database_script.sql — структура и данные; test_queries.sql — проверки
tests/RulesChecks/      программа проверок расчётных правил и операций сервисов
docs/                   ER-диаграмма, результаты проверок
resources/sources.txt   происхождение изображений
```

## Запуск

1. В SSMS выполнить `database/database_script.sql` целиком (создаёт базу `bookstore` и заполняет её).
2. В `src/Ktpt.Bookstore/connection.txt` указать свой сервер, например:
   `Server=.\SQLEXPRESS;Database=bookstore;Trusted_Connection=True;Encrypt=True;TrustServerCertificate=True;Connect Timeout=5`
3. Собрать и запустить:

```
cd src/Ktpt.Bookstore
dotnet run
```

Проверки правил и сервисов (нужна база `bookstore`):

```
cd tests/RulesChecks
dotnet run
```

Публикация папки для другого ПК: `dotnet publish src/Ktpt.Bookstore -c Release -r win-x64 --self-contained false -o publish`,
затем рядом с `Ktpt.Bookstore.exe` поправить `connection.txt`.

## Ограничения

- вход без пароля; права проверяются в сервисах, но человек с доступом к таблицам через SSMS может обойти правила приложения;
- новый заказ содержит одну позицию (одну книгу);
- печать документов (чек, накладная) не реализована.
